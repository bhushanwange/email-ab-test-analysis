# Email Campaign A/B Test Analysis

Concise Jupyter Notebook analyzing A/B test conversion rates, two-sample t-test p-values, and 95% confidence intervals for an email campaign[cite: 8].

## Steps Covered
1. Loaded A/B test data using `pandas`[cite: 8].
2. Calculated conversion rates for each campaign group[cite: 8].
3. Ran a two-sample t-test and extracted the p-value[cite: 8].
4. Computed the 95% confidence interval for the conversion difference[cite: 8].
5. Summarized findings and conclusions in Markdown[cite: 8].
